Softcenteric Admin Login
========================

Login URL (primary):
  /admin/login

Login URL (short):
  /login
  (redirects to /admin/login)

Local example:
  http://localhost:3000/admin/login
  http://localhost:3000/login

Credentials (demo)
------------------
Email:    admin@softcenteric.com
Password: Admin@123

Notes
-----
- These are demo credentials defined in lib/adminAuth.js
- Session uses a JWT (lib/jwt/init.js) that expires after 1 day
- After expiry, admin redirects to /admin/login
- After login you land on /admin
- Production images (Vercel): upload locally to public/uploads, commit those files,
  save only /uploads/... URLs in the DB, then push/redeploy. Runtime uploads on
  Vercel do not persist (no Vercel Blob). Sync URLs with: npm run db:seed-uploads
- Not production-grade security — change ADMIN_JWT_SECRET before a real public deploy
